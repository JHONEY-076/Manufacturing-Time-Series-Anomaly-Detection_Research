02 웹페이지에서 세 모델 비교

  1. 대시보드에서 ‘서버 연결됨 · 3개 모델’을 확인합니다.
  2. 정상 샘플 또는 이상 샘플을 클릭합니다. 원본 파일 이름, 구간 시각, 데이터에 기록된 정답이 표시됩니다.
  3. 세 모델 비교 실행을 누릅니다. 실제 POST /compare 요청이 서버로 전송됩니다.
  4. 오른쪽 카드에서 Baseline, Magnitude warping, FMD의 정상/이상 판정, 이상 점수, 기준값, 추론시간을 확인합니다. 원본 정답과 모델 판정은 별개입니다.
  5. 10개 순서대로 재생을 누르면 선택한 윈도부터 시간 순서대로 최대 10개가 전송됩니다. 각 응답 후 1초를 기다립니다. ‘재생 중지’로 다음 요청을 멈출 수 있습니다.
  6. 응답 JSON 저장으로 현재 요청·응답을 저장하거나, ‘전체 검증 결과’ 탭에서 3,081개 윈도의 종합 성능표와 그래프를 확인합니다.
API 체험의 응답시간은 방금 보낸 요청의 측정값입니다. 전체 검증 탭의 수치는 이전에 수행한 전체 평가 기록입니다. 저장 데이터를 재생하는 기능이며 실제 설비에 연결된 실시간 수집 화면은 아닙니다.

03 내 센서 데이터를 넣는 방법

‘요청 JSON 확인 · 수정’을 펼치거나 ‘내 JSON 불러오기’를 눌러 입력합니다. 그대로 사용할 수 있는 실제 요청 JSON 예시도 제공합니다.

입력 조건규칙
행동일한 파일·설비에서 시간 순서대로 모은 30개 관측
열 순서RealPower, GateOnTime, SetPower, Speed, Length
값학습 데이터와 같은 단위의 정규화 전 숫자
정규화서버가 학습 때의 평균·표준편차를 적용
제외할 필드label, PageNo, WorkingTime 등은 요청에 넣지 않음

요청은 feature_names와 window만 갖습니다. 예시 파일을 내려받아 30행 × 5열의 센서값을 바꾸면 됩니다. 원본 CSV를 직접 업로드하는 화면은 아니며, CSV는 아래처럼 JSON으로 변환할 수 있습니다.

# 연구 폴더에서 실행하는 Python 코드 예시
import pandas as pd
import httpx

features = ["RealPower", "GateOnTime", "SetPower", "Speed", "Length"]
frame = pd.read_csv("data/raw_data/test/WeldingTest_01_OK.csv")
payload = {
    "feature_names": features,
    "window": frame.loc[:, features].iloc[:30].to_numpy().tolist(),
}
with httpx.Client(trust_env=False) as client:
    response = client.post("http://127.0.0.1:8000/compare", json=payload)
    response.raise_for_status()
    print(response.json())

센서가 한 행씩 들어오는 별도 시스템에서는 최근 30행을 버퍼에 모은 뒤 API로 보냅니다. 서로 다른 설비 데이터를 한 윈도에 섞지 마세요. 현재 API는 완성된 30시점 윈도를 입력받습니다.

04 Swagger 또는 PowerShell로 직접 호출

Swagger: /docs를 열고 POST /compare → Try it out → 예시 요청 JSON 붙여넣기 → Execute를 누릅니다. 응답 코드가 200이면 요청이 성공한 것입니다. POST /predict/{model_name}에서는 모델 이름을 선택해 개별 추론할 수 있습니다.

주소동작
GET /health서버·모델 로딩 상태
GET /models센서 순서·학습 설정·기준값
POST /compare세 모델을 같은 입력으로 비교
POST /predict/baselineBaseline 단독 추론
POST /predict/magnitude_warpingMagnitude warping 단독 추론
POST /predict/fmdFMD 단독 추론

PowerShell 예시:

cd "C:\Users\gram\Desktop\Research"
$requestBody = Get-Content -Raw -Encoding UTF8 data\research11\results\example_request.json
$result = Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/compare -ContentType 'application/json' -Body $requestBody
$result | ConvertTo-Json -Depth 10

anomaly_score ≥ threshold이면 prediction=1·label="anomaly", 그렇지 않으면 prediction=0·label="normal"입니다. 모델별 threshold가 다르므로 점수의 크기만으로 세 모델의 우열을 판단하면 안 됩니다.

05 서버 종료와 문제 해결

Stop_API.cmd를 더블클릭하면 실행 도우미가 시작한 이 프로젝트 서버가 종료됩니다. PowerShell에서는 다음 명령을 사용합니다.

.\.venv-api\Scripts\python.exe tools\research11_service.py status
.\.venv-api\Scripts\python.exe tools\research11_service.py stop
# 코드를 수정한 뒤 다시 시작
.\.venv-api\Scripts\python.exe tools\research11_service.py restart --open
