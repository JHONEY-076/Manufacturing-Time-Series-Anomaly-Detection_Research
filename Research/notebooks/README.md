# 연구 과정 노트북

Research01–09 노트북은 당시 분석과 실험을 진행한 과정을 보여줍니다. 코드와 설명 셀을 공개하며, 실행 출력·실행 횟수·셀 메타데이터는 정리했습니다. 원본 노트북은 로컬 `.local-only/public-structure-originals/`에 보관합니다.

노트북 파일 번호와 `data/researchXX`의 실험 번호는 항상 일치하지 않습니다. 내용과 루트 README의 연구 단계 설명을 함께 확인하세요. 기존 노트북은 연구 이력이며 최신 분할 수정 사항이 모두 반영된 실행본이라는 의미는 아닙니다.

현재 저장소에는 연구 입력 데이터를 포함합니다. 노트북의 추가 환경은 별도로 준비해야 하며, 현재 평가를 실행할 때는 공통 진입점 run.py를 사용하세요. [실행 안내](../../docs/reproduction.md) · [최신 비교](../../docs/latest-results.md)
