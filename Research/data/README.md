# 연구 단계별 데이터와 결과

폴더 순서는 원본 자료 → 전처리 → 분할 → 기준 모델 → 증강·평가·민감도 분석의 연구 흐름을 나타냅니다. 각 폴더의 README와 선별한 `results/` 집계 파일을 공개합니다.

원본 센서 데이터, 전처리 배열, 생성 표본과 행별 메타데이터는 포함하지 않습니다. 빈 입력 폴더 대신 README에 필요한 자료와 역할을 설명했습니다. 공개 결과만으로 전체 학습을 재실행할 수는 없습니다.

기존 Research01–10 결과에는 이후 발견된 분할 중첩의 한계가 있습니다. [최신 비교와의 구분](../../docs/latest-results.md)을 확인하세요.
