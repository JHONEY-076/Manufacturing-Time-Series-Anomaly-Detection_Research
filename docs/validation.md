# 실행 검증 기록

2026-11-07 저장소를 실행 가능한 형태로 정리하며 기본 평가 경로를 실제 실행했습니다. 기준 환경은 Python 3.13, NumPy 2.3.5, pandas 3.0.3, scikit-learn 1.8.0, matplotlib 3.10.7, seaborn 0.13.2입니다.

## 확인한 범위

- 입력 27개 파일의 SHA-256 및 분할 구조 확인
- 원본 CSV와 기존 메타데이터에서 윈도우 재구성: 4개 분할의 X·y가 제공된 배열과 정확히 일치
- 저장된 생성 후보를 사용하는 11개 조건 비교: 각 RF 학습, 검증 임계값 선택, 평가, 개별 예측·환경·해시 저장
- 공개 대상 파일만 별도 로컬 폴더에 복사해 입력 검사·윈도우 재구성·11개 조건 비교 재실행: 첫 실행과 지표 CSV가 정확히 일치
- 저장한 개별 예측에서 Precision·Recall·F1·F2·AP·AUROC를 다시 계산해 CSV와 대조

별도 폴더 검증에서도 동일한 설치 패키지를 사용했습니다. 새로운 가상환경에 패키지를 다시 내려받는 설치 검증은 수행하지 않았으며, 기본 요구 버전과 실제 설치 버전은 일치하는지 확인했습니다.

이번 실행의 지표와 조건은 [실행 결과 CSV](results/reproduction/main_comparison.csv)와 [환경·입력·코드 기록](results/reproduction/run.json)에 보존합니다. 과거 기록 수치와 현재 환경의 재실행 결과는 완전히 같지 않으므로 별도 결과로 제공합니다. 과거 결과의 정확한 환경·입력·코드 조합이 모두 고정됐다고 주장하지 않습니다.

현재 실행 경로는 고정된 입력과 환경, 파라미터, 코드 해시를 기록해 이후 실험의 비교 기준으로 삼을 수 있도록 구성했습니다. 생성기는 재학습하지 않았습니다.

## 이번에 다시 수행하지 않은 범위

- GT-GAN·Diffusion 전체 재학습과 GPU 검증
- 클래스 구성·민감도 분석·30회 반복 전체 실행
- API 환경 재설치 및 HTTP·브라우저 검증
- macOS·Linux에서의 실제 실행

기본 실행 경로는 pathlib와 프로젝트 기준 경로를 사용하며 특정 Windows 사용자 폴더에 의존하지 않습니다. 실행 환경별 차이는 결과의 run.json과 함께 검토해야 합니다.
